# PropertyManager

A portfolio-quality property management web application for a small/medium property management company, built with SQL Server, FastAPI and React.

This repository is under active development. See [documentation/project-scope.md](documentation/project-scope.md) for the full project scope, database design, API plan, and the AI prompt library used to build this project one feature at a time.

## Status

Early setup — repository structure only. No business features yet.

## Stack

- **Database:** SQL Server
- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic, JWT auth, Pytest
- **Frontend:** React, React Router, Axios

## Repository layout

```text
backend/        FastAPI application
frontend/       React application
database/       SQL Server scripts (schema, constraints, seed data, reports)
documentation/  Project scope, design docs, and setup guides
```
